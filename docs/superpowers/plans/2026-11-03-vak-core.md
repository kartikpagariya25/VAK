# VAK Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build VAK build 1: a native WPF notch app with shell, header, dock, Home, System, Clock, Timers and Settings.

**Architecture:** `VAK.Core` (no UI) holds settings, widget registry, timer/clock logic and system-service interfaces; `VAK.App` (WPF, MVVM) holds the shell window, design system and one card + page view per widget. Logic is test-first in Core; UI is verified by running the app against the reference screenshots.

**Tech Stack:** .NET 8, WPF, CommunityToolkit.Mvvm, NAudio (MIT), xUnit; Inter + Geist fonts (OFL), Fluent System Icons (MIT).

**Spec:** `docs/superpowers/specs/2026-11-03-vak-core-design.md`

## Global Constraints

- Target framework `net8.0-windows10.0.19041.0` for both `VAK.Core` and `VAK.App` (WinRT battery API); tests use the same.
- Solution layout is exactly `src/VAK.App`, `src/VAK.Core`, `tests/VAK.Core.Tests`.
- Settings file: `%AppData%\VAK\settings.json`; a corrupt file is kept as `settings.json.bak` and defaults load.
- Nothing leaves the machine in build 1 (no network calls).
- Tokens: panel `#000000`, card `#0D0D0F`, inner control `#2A2A2C`, accent `#2F7CF6`, primary button `#1D64D8`, active dock button white.
- Expanded panel is 800 x 388 DIP, centered at the top; pill-to-panel animation about 250 ms, eased.
- Default hotkey `Ctrl+Alt+Space`.
- Any failing data source shows "-" on its card; never a crash or dialog.
- Fonts and icons come from their official upstream releases, never extracted from Vayli. No Vayli code, art or logo is copied. Ship the OFL/MIT license texts.
- Installing the .NET 8 SDK needs the user's explicit approval first.

## Review Focus

- No battery (desktop PC): Battery card and header battery show "-"/hide, no exception. (Task 7, 10, 12)
- Truncated, empty or unknown-field `settings.json`: app starts with defaults. (Task 2)
- Hotkey already taken by another app: no crash; tray shows a one-time notice. (Task 9)
- Display scale 100%-200% or monitor change: panel stays centered at the top of the primary display. (Task 9)
- Sleep/resume or a huge timer tick: a Pomodoro phase advances at most once per tick. (Task 4)
